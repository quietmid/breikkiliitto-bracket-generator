# breikkiliitto-bracket-generator

I am the chairperson for Suomen Breikkiliittoo Ry, the Finnish Breaking Association, also an event planner, mostly for breaking competition and I just thought this would had been very helpful for our event. 

A bracket generator for Dance competition

https://quietmid.github.io/breikkiliitto-bracket-generator/


Enter a category count from 1 to 6 and select **Start**. Name each category and enter its team count (2–64), then select **Generate brackets**. The full-screen bracket page creates a single-elimination bracket for each category, mirrored on both sides with the final in the center. Enter team names in the opening round and select winners to advance them; byes advance automatically. Optionally enable a third-place match below the final to match the semi-final losers. Category names, team names, and selected winners are saved for the current browser session.

On the first page, optionally select **Choose photo** to use an image smaller than 24 MB from your device. The photo is resized and kept in the current browser session; it is not uploaded. It will appear behind every category bracket until the session ends. You can remove it or choose a different photo before starting.
